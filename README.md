# Phrasal Verbs

Colección personal de phrasal verbs en inglés, con significado, traducción al español y ejemplos. Un archivo por cada phrasal verb.

## Índice

| Phrasal verb | Significado |
|---|---|
| [use up](phrasal-verbs/use-up.md) | Consumir por completo, agotar |

## Formato de cada archivo

```markdown
# Phrasal verb

## 1. Significado en español
- **Meaning:** definición en inglés.
- **Spanish:** traducciones.
- **Examples:**
  - *"Frase en inglés."* (Traducción.)
```

Si un phrasal verb tiene varios significados, se añaden como `## 2.`, `## 3.`, etc.

## Cómo añadir uno nuevo

Usa la skill `phrasal-verb`:

> `/phrasal-verb` give up

Crea el archivo en `phrasal-verbs/` y añade la fila al índice.

## Estructura

```
phrasal-verbs/
├── use-up.md
├── give-up.md
└── ...
```
